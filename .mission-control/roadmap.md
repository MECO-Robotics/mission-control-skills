# Mission Control Roadmap

## Near-term

- Finish coordinator bootstrap and state validation coverage.
- Add lightweight agent prompts for cross-repo change tracking.
- Run first wiki snapshot generation from current state files.

## Mid-term

- Add optional relationship fields for Nexus-backed issue/branch/PR metadata.
- Introduce a structured changelog tied to cross-repo milestones.
- Create shared reporting templates for multi-repo dependency risk.

## Long-term

- Add automated ingestion hooks from release and issue workflows.
- Expand role prompts into repository-specific operating plans.
- Publish a first-party wiki sync action that consumes this repository as source of truth.
